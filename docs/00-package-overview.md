# QuestMap Development Package

QuestMap is a gamified academic planning application for college students who struggle with executive function, time awareness, prioritization, and long projects that become urgent too late.

The app converts syllabi, recurring commitments, assignments, grades, and project milestones into a trustworthy weekly plan. It presents the plan through an optional quest or mission theme while retaining conventional academic terminology underneath.
